Setup guide

Install Logilator, connect it to Bybit, and place your first test order. About ten minutes on Windows.

Before you start

You need a Windows 10 or 11 PC, a Bybit account, and about ten minutes. Logilator runs entirely on your computer and talks only to Bybit (and OpenRouter if you use Logic AI).

Start on demo. Use Bybit Demo Trading or the Bybit testnet first. Both use fake money. Move to a live account only after you have checked that every number and every order looks right.

1. Install Node.js

Logilator needs Node.js, a free program that runs it. Download the LTS version from nodejs.org and install it with the default options. To check it worked, open the Start menu, type cmd, press Enter and run:

node --version

If it prints a version number, you're set.

2. Download and unzip

Unzip the Logilator folder somewhere you'll find it again, for example Documents. Don't run it from inside the zip file. You should see start.bat, server.js, a public folder and a file called .env.example.

3. Create a Bybit API key

Logilator needs an API key so it can read your balance and place orders. Use trading permission only. Never enable withdrawals or transfers.

Option A: Demo Trading (recommended to start)

  1. Log in at bybit.com and switch to Demo Trading from your profile menu.
  2. In Demo Trading mode, open your avatar menu and choose API, then create a new key.
  3. Choose a system-generated key with Read-Write permission, and tick only the order and position permissions for USDT derivatives (Orders, Positions).
  4. Copy the API key and API secret. The secret is shown only once.

Option B: Testnet

  1. Create a separate account at testnet.bybit.com and request test funds from the Assets page.
  2. Open Profile, API and create a key with the same permissions as above.

Option C: Live account

Create the key in your normal account with the same permissions. Restrict it to your IP address if Bybit offers that. Only do this after you have tested on demo.

Never share your API secret with anyone, including anyone claiming to be Logilator support. We will never ask for it. A demo key and a live key are different keys; the key must match the environment you set in the next step. Bybit's menu names change from time to time, but the rule stays the same: trading permissions only, never withdrawals.

On the Bybit trading page, set the account to Isolated Margin and One-Way position mode. Logilator checks both and refuses to trade otherwise.

4. Add your keys

  1. In the Logilator folder, copy .env.example and rename the copy to .env. If Windows hides file extensions, make sure it is .env and not .env.txt.
  2. Open .env in Notepad and fill in the top section:
BYBIT_ENV=testnet        # or demo, or mainnet. Must match where the key was created
BYBIT_API_KEY=your_key_here
BYBIT_API_SECRET=your_secret_here

For Demo Trading you can also write BYBIT_IS_DEMO=true. Save the file. Never share it or post it online.

Optional safety limits

The same file lets you set a maximum risk per trade (MAX_RISK_USDT), a daily loss limit (MAX_DAILY_LOSS_USDT), your own fee rates if you have a VIP tier, and DRY_RUN=true to check everything without sending any order.

5. Start Logilator

Double-click start.bat. A black window opens and prints the address, normally http://localhost:3000. Open that address in your browser. Keep the black window open while you use Logilator; closing it stops the app.

The calculator should show your balance within a few seconds. The badge next to the order button shows the environment you're connected to: TESTNET, DEMO or LIVE.

6. Test safely

  1. With DRY_RUN=true, enter a trade and press Place Order. You'll see the order review and what would be sent, but nothing is sent.
  2. Turn dry run off, still on demo or testnet, and place a small order. Watch it appear in Bybit.
  3. When the trade closes, open the Journal tab to see it recorded.
  4. Only then consider a live account, and start small.

Logic AI (optional)

Logic AI needs your own free key from openrouter.ai (Keys). Paste it into .env as OPENROUTER_API_KEY= and restart Logilator. Free models cost nothing but have daily limits. Paid models bill your own OpenRouter credits and the app asks before using them. Logic AI never sees your Bybit keys and cannot place an order without your confirmation.

Taskbar shortcut

Double-click Create Shortcut.bat. It creates a Logilator shortcut in the folder. Right-click the shortcut, choose Show more options, then Pin to taskbar.

Troubleshooting

start.bat closes immediately

Node.js is probably not installed or not on your PATH. Reinstall it, restart the PC and try again.

“Keys not configured” or balance won't load

Check that the file is called .env, that the key and secret have no spaces or quotes around them, that BYBIT_ENV matches where the key was made, and restart Logilator after any change.

Bybit says the API key is invalid or the permissions are wrong

A demo key only works with demo, a testnet key only with testnet, and a live key only with mainnet. Make sure Orders and Positions permissions are enabled, and that your IP address matches if you restricted the key.

The order is blocked

Read the message in the order window. Common reasons: the account isn't in isolated margin or one-way mode, you already have a position or open order on that symbol, or one of your own safety limits was reached.

The page is blank or the port is busy

Another program may be using port 3000. Change PORT in .env to another number such as 3001 and open that address instead.

Still stuck? See the support page. Include what you did and the message you see. Never include your API secret.
